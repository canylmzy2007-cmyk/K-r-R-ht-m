# Kör Rıhtım – v1.0.0

Kör Rıhtım is a zombie survival game developed using Python.

## How to Download and Play

1. Go to the **Releases** section.
2. Download the **KorRihtim.zip** file.
3. Extract the ZIP file into a folder.
4. Open the extracted folder.
5. Double-click **OYNA.bat** to launch the game.

## Important Notes

- This game is designed for Windows.
- This is my first game development project, and I am still learning.
